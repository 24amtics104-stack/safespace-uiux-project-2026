# SafeSpace – Responsive Landing Page

## Project Overview

SafeSpace is a UI/UX design project created using Figma. It is an educational platform concept that helps students learn about digital privacy, password safety, and online scams.

## Target Audience

* College students
* Beginners learning about cybersecurity
* Everyday internet users

## Objectives

* Create an attractive and user-friendly landing page.
* Design desktop and mobile layouts.
* Use Auto Layout in Figma.
* Create reusable components.
* Maintain consistent colors, typography, and spacing.

## Main Sections

1. Navigation Header
2. Hero Section
3. Features Section
4. How It Works
5. Learning Resources
6. Frequently Asked Questions
7. Call-to-Action Section
8. Footer

## Reusable Components

* Primary Button
* Secondary Button
* Feature Card

## Design Choices

The design uses a dark navy background, purple buttons, and cyan highlights. Clear typography, rounded cards, and consistent spacing help make the interface visually appealing and easy to understand.

## Tools Used

* Figma
* Figma Auto Layout
* Figma Components
* Shared Color and Typography Styles

## Deliverables

* Desktop landing page
* Mobile landing page
* Reusable components
* Design screenshots
